# Product documentation

This is a product documentation template: onboarding, do’s and don’ts, architecture, and workflow.

```bash
pnpm dev
```

build production version

```bash
pnpm build
```

The site is bilingual (`/` English, `/de/` German). Content lives in `src/content/docs/`. Sidebar and locales are configured in `astro.config.mjs`.

Sections: getting started, how-to guides, do’s and don’ts, architecture, workflow, reference.
